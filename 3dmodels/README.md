# Custom library assets

The custom footprints, symbol libraries and STEP models bundled with this project
were copied from the existing design's local KiCad libraries on 2026-09-17.
Existing creator and manufacturer metadata are retained in the library files.
The normalized project-local fuse symbol is retained. Imported symbol default
footprint names now resolve through the project library table. Footprint model
assignments and transforms were copied from the PCB, with paths made relative to
`${KIPRJMOD}`. PCB placement, routing and model transforms are unchanged.

These third-party assets retain their original licences and notices, as described
in the repository's NOTICE; bundling does not relicense them under CERN-OHL-P-2.0.
The original local files did not include separate licence files.
